# AI-пайплайн

```
Microphone → AVAudioEngine (m4a) + SFSpeechRecognizer (live draft)
   ↓ /transcribe  (Gemini, аудио inline)        → original + clean transcript, language
   ↓ /parse       (Gemini, responseSchema)      → items[] с семантическими датами и confidence
   ↓ resolve.ts   (код)                         → абсолютные даты, id проектов/людей, приоритет, auto_file
   ↓ Review UI    («Я нашёл N действий»)         → правки, выбор при неоднозначности
   ↓ /commit      (tools.ts, undo-батч)          → tasks, reminders, projects, people
   ↓ iOS          → уведомления, EventKit, Apple Reminders, sync
```

## Семантические даты
| Токен `day` | Значение |
|-------------|----------|
| `today`, `tomorrow`, `day_after_tomorrow` | относительно локальной даты пользователя |
| `weekday:fri` | ближайшая пятница (сегодня включительно) — «до пятницы» |
| `next_weekday:mon` | день в следующей календарной неделе |
| `next_week` | дедлайн = пятница следующей недели |
| `this_week` / `end_of_week` | пятница (или воскресенье, если уже выходные) |
| `end_of_month`, `next_month` | последний день месяца / 1-е число следующего |
| `in_days:N`, `in_weeks:N`, `in_hours:N`, `in_minutes:N` | относительно «сейчас» |
| `date:YYYY-MM-DD` | явная дата |

`time`: `morning | day | evening | night | HH:mm` → из профиля (по умолчанию 09:00 / 14:00 / 19:00 / 22:00).
Без времени: срок → `end_of_day` (18:00), напоминание → утро, событие → 09:00. Неизвестный токен → `null` (модель не угадывает, пользователь увидит предупреждение).

## Классификация
1. Промпт содержит дерево Workspace → Project → Area (+ синонимы), людей, организации, правила маршрутизации и выученные исправления.
2. `matching.ts` сопоставляет предложенные имена с существующими (точное совпадение, синоним, префикс, пересечение стемов). «Страховое покрытие» → существующее «Страхование».
3. Правила профиля (`"риски" → "Казмортрансфлот/Управление рисками"`) и исправления пользователя (≥3 раза) переопределяют выбор модели.
4. `confidence ≥ auto_file_threshold` (по умолчанию 0.85) и нет альтернатив → распределяется автоматически; иначе экран предлагает выбор «КМТФ → Страхование или КМТФ → Риски».

## Приоритеты
Модель предлагает, код проверяет: P1 только при словах «срочно / критично / обязательно сегодня / до заседания» или заполненном `priority_reason`; «важно / не забыть» → P2; «когда-нибудь» → P4.

## Чат и инструменты
`chat/index.ts` ведёт цикл function calling (до 6 раундов). Инструменты: `list_tasks, search_tasks, get_task, create_task, update_task, complete_task, move_task, delete_task, reschedule_tasks, create_reminder, create_project, create_area, create_person, create_calendar_event`.
Чтение выполняется сразу; `delete_task`, `reschedule_tasks`, `create_calendar_event` возвращают `requires_confirmation`, клиент показывает карточку «Подтвердить / Отклонить» и вызывает `/execute-actions`. Любой батч можно откатить через `/undo` (кнопка UNDO в приложении).

## Обучение на предпочтениях (§40)
`preference_profiles` хранит время суток, приоритет по умолчанию, порог, синонимы, правила маршрутизации, режимы приватности. Перенос задачи в другую категорию в приложении вызывает RPC `record_correction`; `routing_hints` агрегирует паттерны и попадает в контекст парсера.

## Критерий качества (§45) и приёмочный сценарий (§46)
`backend/tests/resolve.test.ts` проверяет: 4 независимых действия, правильные проект/направление, сроки (завтра → 18:00, пятница), waiting + follow-up, напоминания «сегодня вечером» / «завтра утром», дедупликацию, запрос уточнения при низкой уверенности, создание неизвестного человека (Артур) при commit.
